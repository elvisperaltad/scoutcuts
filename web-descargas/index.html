Qué hacer cuando termine la descarga

  1. El archivo que se baja es un ZIP. Extrae todo el ZIP en una carpeta de tu computadora (clic derecho sobre el archivo → Extraer todo).
  2. No abras el programa desde dentro del ZIP: primero hay que extraerlo completo, si no, no funciona.
  3. Entra en la carpeta que acabas de extraer y abre INICIAR_CORTADOR.bat con doble clic.
  4. Si no abre o se cierra solo, abre DIAGNOSTICO.bat (está en la misma carpeta), toma una captura de pantalla completa de lo que aparece y envíanosla. Con eso sabemos qué pasó.

Antes de empezar

  • Necesitas una computadora con Windows. No funciona en teléfonos ni tablets.
  • No hace falta instalar nada más: el programa trae todo lo que necesita dentro.
  • El archivo es grande, así que conviene descargarlo con una conexión estable y no apagar la computadora mientras baja.
  • Para subir videos desde el teléfono, usa scoutcuts.com.

Tu código es personal. No lo compartas ni lo pegues en grupos: cualquiera con ese código podría usar tu cuenta.
